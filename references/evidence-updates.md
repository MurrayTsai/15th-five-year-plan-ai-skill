# 现实证据与地方落实

目录：何时查；查什么；记录与冲突；复核与更新。

## 何时查

本包内置国家纲要原文和分析，不内置全国地方政策、实时招聘或薪酬统计。每次要下当前可执行结论时，针对决定查询最新证据。用户只问原文含义时，不必扩成实时研究。不得声称已自动监控；需要定期提醒或监测时使用可用自动化能力并核实实际创建结果。

## 查什么

先列关键主张与证据缺口，再决定查询范围。以下是来源类型与检索模板，不是已经核查的最新事实。

|问题|优先来源|检索模板/核对内容|
|---|---|---|
|国家实施与专项政策|发布机关正式文件、国务院及主管部门发布|“主题 十五五 实施方案 发布机关”；全文、文号、附件、适用期|
|地方落实|省市县政府、发改及业务主管部门|“地区 主题 实施细则 申报”；国家、省、市文件分别记录|
|补贴资格|办理部门的现行申报指南、窗口公告|对象、材料、地区、截止时间、预算、重复享受限制、实际受理|
|项目阶段|核准机关、项目业主、官方采购或招标平台|批准、招标、开工、验收、投运分开；中标不等于已回款|
|行业运行|统计部门、主管机关、可查方法的行业数据|所属期、样本、统计范围、价格与数量、同比与环比|
|公司业务|企业正式披露、产品资料、合同/采购信息|收入来源、客户、现金流、应收、持续经营及可信度|
|岗位与待遇|雇主官网/招聘、实际offer、可验证从业访谈|样本日期、地点、工作内容、硬要求、薪酬构成、广告是否仍有效|
|海外业务|目的地主管机关、海关、移民/劳动/税务规则|产品、合同主体、国籍/居留、资金与数据路径；中国规划不能代替当地规定|

官方来源优先但也要区分文件性质：征求意见、倡议、讲话、答问、正式规则、执行通报。媒体可帮助发现线索，适用条件应回到原文件。只搜索摘要而打不开正文时标为未核全文。具体法律、金融、医疗问题按现行权威来源核查。

## 记录与冲突

使用 `python3 scripts/evidence.py --template` 获取空白记录，将任务证据保存在当前任务中；不要把用户私密合同、履历或财务信息加入通用skill。

字段包含：主张、证据类别、标题/发布者/URL、发布日期、数据期、采集日期、地域、文件状态、生效与失效日期、关联章节、转述或短摘录、口径/限制、复核日、核查状态。未知填null并说明，不能补造日期。核查工具只检查结构和日期，不验证内容真伪。

```bash
python3 scripts/evidence.py --validate /absolute/path/evidence.json --as-of 2026-10-23
```

来源重复转载不算独立证据。主张互相冲突时，先查统计期、地域、对象、定义、样本和文件效力；保留旧证据并用 `supersedes` 指明被替代记录，不直接覆盖历史。后发文章不自动优于仍有效的正式规则。招聘只能支持所见样本，不能外推行业净岗位或典型工资。

## 复核与更新

复核频率由变化速度和决定期限决定：临近申报、签约、出资或出行时重新核查；统计数据按发布周期更新；规划原文按版本核验。`review_after`是提醒日期，不是证据自动失效日。生效尚未来临、过期、未核全文和日期未知的证据不能支撑“现在可以办理”的肯定判断。

不能联网、登录受限或来源缺失时，明确“现实执行尚未核查”，给依据文本的条件分析与最少补证步骤，不制造薪酬、市场规模、有效补贴或审批进度。政策解释卡中的观察项目是待查清单，不是已经观察到的变化。
